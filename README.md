## 1. 这个项目是什么

ai-resume2.0 是一个免费开源的 AI 简历工具。它会和你聊天，了解你的经历，然后自动帮你生成一份专业的简历。

- **AI 对话生成** - 像聊天一样，AI 帮你挖掘经历、组织语言
- **多模板选择** - 多种简历模板，一键切换
- **PDF 导出** - 生成后可直接下载 PDF
- **简历解析** - 上传已有简历，AI 帮你优化
- **完全免费** - 代码开源，不收费，不限制次数

你需要自己准备一个 AI 服务的 API Key（下面会详细说明）。

## 我们能做什么

### 你不用会写简历，跟它聊就行

最讽刺的事：**活干得最多的人，往往简历写得最烂**。你在项目里忙前忙后，落到纸上就变成"负责XX工作""参与XX项目"——HR 扫一眼就知道又是个模板货，直接划走。憋一下午写出三行字，自己都看不下去。这个工具不要求你会写，它像个懂行的朋友坐对面问你：你在项目里到底干了什么？最难的问题怎么解决的？你只管回答，它替你把经历翻成 HR 想看的话。

### 它真的研究过岗位在筛什么人

**海投 100 份零回复，问题从来不是你不行，是你的简历跟岗位不在一个频道上。** 你写的是"我很努力"，HR 要看的是"你能不能干这活"。市面上大部分 AI 简历工具给所有岗位生成同一份东西，换个抬头接着投。这个项目内置了真实岗位知识库：HR 先看什么、面试追问什么、什么样的经历值钱、普通经历怎么翻译成岗位要的能力——你说投产品经理就按产品经理写，说投主播就换一套逻辑。

### 三种情况，三种入口

**没简历的、简历过时的、不知道自己能干啥的，痛点根本不一样。** 应届生没实习经历写什么？转行的人上一份工作和新方向八竿子打不着？工作五年简历还是毕业那一版？一个入口装不下所有人。它分成三条路：旧简历直接传上来帮你诊断改；知道要投哪个岗位就针对性问、针对性做；完全不知道干啥，它根据你的背景帮你分析方向，边推荐边出简历。

### 做完直接下载 PDF，模板随便换

**最气人的往往是生成完那一步。** AI 帮你写完了，你复制进 Word——格式全乱、对齐错位、字体变形，折腾半小时。改一句话，整篇重新排。投不同岗位还得换风格：投大厂要商务版，投互联网要简洁版，投校招要校园版，每版排一次。这里生成出来就是定稿，PDF 一键下载，模板随时切，改完直接投。

### 你的简历不会经过任何服务器

**简历是什么？是你姓名、电话、身份证信息、薪资期望的全集。** 你把它上传到某个在线工具，等于把全部隐私交出去——它存不存？卖不卖？会不会被爬？这个项目没有后端数据库，不注册、不登录、不收集数据，你填的 Key 只存在自己浏览器里，甚至可以整个部署在自己电脑上，全程只有你看得见。

### 完全免费，不限次数，代码全开源

**简历哪有改三版就够的？** 投产品改一版、投运营改一版、HR 反馈回来再改一版。按次收费的工具改两版你就开始犹豫了，月费订阅的你一个月也就用那几次。改简历本来就不该按次要钱。这里所有功能免费，没有次数限制，MIT 开源，你可以自己部署、自己改。

## 3. Windows 怎么运行

1. 下载本项目（ZIP 解压 或 git clone）
2. 打开项目文件夹
3. **双击 `start.bat`** 文件
4. 脚本会自动检查环境、安装依赖、启动服务、打开浏览器

就这么简单。第一次运行会安装依赖，可能需要几分钟，请耐心等待。

## 6. 第一次打开后怎么配置 API

第一次打开网站时，会先弹出「必读的小提示」，看完后你会看到 API 配置页面。

1. 在输入框中粘贴你的 API Key
2. （可选）点击「高级设置」可以修改 Base URL 和模型名称
3. 点击「确认并继续」
4. 开始使用

你的 API Key 只保存在你的浏览器本地，不会上传到任何服务器。清除浏览器数据或更换设备后需要重新输入。

---

## 7. 以后怎么更换 API

API Key 保存后，再次打开网站不需要重新输入。

如需更换 API Key 或切换模型服务商：

1. 在首页右上角点击「API 设置」
2. 修改你的 API Key / Base URL / 模型
3. 点击「保存设置」

更换后立即生效，后续请求会使用新的配置。

## 8. 推荐使用什么 API

**推荐使用 DeepSeek。**

原因：
- 价格便宜，适合个人使用
- 注册简单，充值方便
- 与本项目默认配置一致，开箱即用

本工具支持任何兼容 **OpenAI API 格式** 的模型服务。只要服务商提供 OpenAI 兼容接口，就可以使用。

常见兼容服务：
- DeepSeek（默认推荐）
- OpenAI 官方
- 硅基流动
- 通义千问（兼容模式）
- 智谱 AI（兼容模式）
- 以及其他任何 OpenAI-compatible 服务

切换方法：在 API 配置页面点击「高级设置」，填写对应的 Base URL 和模型名称即可。

## 9. 如何获取 API Key

### DeepSeek（推荐）

1. 打开 https://platform.deepseek.com/
2. 注册账号
3. 进入「API Keys」页面
4. 点击「创建 API Key」
5. 复制生成的 Key
6. 粘贴到网站的输入框中

> DeepSeek 需要充值后才能使用。最低充值金额很少，一般几块钱就够用很多次。

### 其他兼容服务

如果你已有其他 OpenAI 兼容 API 的 Key，可以直接使用。在输入页面点击「高级设置」，填写对应的 Base URL 和模型名称。

## 10. 常见启动问题

### Q: 提示"未检测到 Node.js"

你没有安装 Node.js。请前往 https://nodejs.org/ 下载并安装 LTS 版本。安装完成后关闭终端重新打开再试。

### Q: 提示"pnpm 安装失败"

可能是网络问题。尝试手动执行：
```bash
npm install -g pnpm
```
如果使用中国大陆网络，可以尝试设置镜像源：
```bash
npm config set registry https://registry.npmmirror.com
npm install -g pnpm
```

### Q: 提示"依赖安装失败"

1. 确认网络连接正常
2. 尝试删除 `pnpm-lock.yaml` 文件后重新运行
3. 尝试手动执行 `pnpm install`

### Q: 提示"端口被占用"或页面打不开

端口 3000 可能被其他程序占用。解决方法：

- 关闭占用 3000 端口的程序
- 或修改启动端口：在命令行中执行 `set PORT=3001 && node scripts/easy-start.mjs`（Windows）或 `PORT=3001 node scripts/easy-start.mjs`（macOS/Linux）

### Q: 浏览器没有自动打开

等服务器启动后（终端显示 "Server listening"），手动在浏览器地址栏输入：http://localhost:3000

### Q: 启动后页面显示错误

1. 检查 API Key 是否正确输入
2. 检查 API Key 是否有余额
3. 尝试换一个浏览器
4. 查看终端是否有错误信息

### Q: API Key 保存在哪里？安全吗？

你的 API Key 和所有个人信息都保存在你自己电脑的浏览器本地（localStorage），不会上传到任何服务器。

- 本项目没有后端数据库
- 不收集任何用户数据
- API Key 只在你调用 AI 时直接发给你选择的 API 服务商

### Q: 换了电脑/浏览器，Key 还在吗？

不在了。因为 Key 保存在浏览器本地，换电脑或换浏览器需要重新输入。

### Q: 可以把项目文件夹直接发给朋友吗？

**不建议。** 如果你已经在浏览器中输入过 API Key，虽然 Key 存在浏览器而不是项目文件夹里，但为了安全起见，推荐让朋友直接从 GitHub 下载干净的项目。

### Q: 端口被占用怎么办？

端口 3000 可能被其他程序占用。解决方法：

- 关闭占用 3000 端口的程序
- 或修改启动端口：在命令行中执行 `set PORT=3001 && node scripts/easy-start.mjs`（Windows）或 `PORT=3001 node scripts/easy-start.mjs`（macOS/Linux）
