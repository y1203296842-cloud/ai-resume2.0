# 果核AI · 岗位简历优化知识库 v2

> **用途**：为 AI Resume Agent 提供岗位深度知识，实现精准简历优化
> **版本**：v2.0
> **更新日期**：2026-08-26
> **结构**：可扩展的多岗位独立知识库

---

## 设计理念

本知识库的核心不是告诉 AI"这个岗位叫什么"，而是让 AI 真正理解：

1. **什么样的人适合这个岗位**
2. **什么经历值钱**
3. **什么能力重要**
4. **用户已有的经历如何转化成岗位真正需要的能力**
5. **简历内容应该如何排序**
6. **什么内容应该弱化或删除**

## 文件说明

### 1. job_profile.md — 岗位画像

- 一句话岗位定义
- 主要工作内容（10条）
- 适合什么样的人
- 岗位细分类型及区别
- 职业发展路径
- 薪资范围参考

### 2. skills.md — 技能需求分析

- **S级技能**：核心竞争能力（必须掌握）
- **A级技能**：高价值能力（重要加分）
- **B级技能**：重要补充能力
- **C级技能**：一般能力
- **D级技能**：低价值或弱相关
- 常见工具清单
- 过时/弱相关技能提示
- 每个技能标注：重要性、为什么重要、如何证明

### 3. hr_preferences.md — HR筛选偏好

- HR最看重的能力（P0/P1/P2优先级）
- 最有价值的经历
- 必须体现的内容
- 几乎没人看的内容
- 容易淘汰的内容
- ATS关键词（50+个）
- 不同企业类型偏好差异

### 4. real_work.md — 真实工作内容

- 从业者一天真实工作流程
- 高频工作任务（15条）
- 常见痛点和挑战
- 新人常见误区
- 行业真实门槛
- 与招聘JD的差异

### 5. interview.md — 面试重点

- 常见面试问题（30个）
- 面试考察重点
- 不同细分岗位的面试差异
- 无经验者如何准备
- 面试成功案例要素
- 常见淘汰原因

### 6. resume_mapping.md — 经历映射（核心文件）

这是整个知识库最重要的部分。对每种常见用户经历，提供：

| 维度 | 说明 |
|------|------|
| **经历名称** | 用户可能输入的经历 |
| **可证明的岗位能力** | 该经历能体现什么岗位能力 |
| **简历价值等级** | 高 / 中 / 低 |
| **推荐表达方向** | 应该如何包装这段经历 |
| **追问点** | Agent 需要追问用户什么 |
| **无数据时的处理** | 用户没有数据时怎么写 |
| **禁止编造的内容** | 绝对不能编造的底线 |

### 7. industry_trends.md — 行业趋势

- 行业最新趋势
- 新兴岗位方向
- 技能需求变化
- 地域分布特点
- 未来发展方向

## 扩展指南

新增岗位时，只需：

1. 创建新目录：`knowledge_v2/新岗位名/`
2. 按照上述7个文件模板生成内容
3. 更新本 README 的目录结构

不需要修改任何代码或系统逻辑。

---

## 内容标准

- **结构化优先**：表格、列表、代码块优于长段落
- **去重**：同一观点只保留最优表达
- **可信度标注**：★1-5 星级
- **可执行性**：每条规则要"明天就能用"
- **禁止**：不要复制原文，不要营销号风格，不要AI洗稿

---

## 使用方式

AI Resume Agent 使用时：

1. **识别目标岗位** → 加载对应目录的知识库
2. **分析用户经历** → 通过 resume_mapping.md 匹配可迁移能力
3. **评估价值等级** → 按 S/A/B 级能力排序简历内容
4. **优化表达** → 使用推荐表达方向升级措辞
5. **追问补全** → 针对缺失信息按追问点提问
6. **排除红线** → 确保不触碰禁止编造的内容
