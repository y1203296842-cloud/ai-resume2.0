# 主播 — 经历映射（最重要）

> 可信度标注：★1-5，★★★★★ 为最高可信度
> 
> 本文件是知识库核心，建立用户经历 → 岗位能力的映射关系，指导Agent追问和简历转化。

---

## 使用说明

对每个经历，Agent应：
1. 识别用户经历的**可迁移能力**
2. 判断**简历价值等级**
3. 按**推荐表达方向**引导描述
4. 通过**追问点**挖掘细节
5. 对**无数据情况**给出替代方案
6. 明确**禁止编造的内容**

## 经历映射表

### 1. 抖音/快手/小红书账号运营

| 项目 | 内容 |
|-----|-----|
| **可证明的岗位能力** | 内容敏感度、平台规则理解、用户思维、流量逻辑、账号运营 |
| **简历价值等级** | ★★★★★（高） |
| **推荐表达方向** | 账号定位→内容策略→数据结果（粉丝量、爆款、引流效果）。突出"从0到1"或"稳定增长"。如果带过货，必须强调GMV |
| **追问点** | ① 账号粉丝量/播放量最高的一条？② 更新频率？③ 有没有直播过？④ 有没有变现？⑤ 为什么停更？ |
| **无数据时的处理** | 强调"持续更新X个月"、"研究了X个竞品账号"、"测试了X种内容形式"，证明执行力 |
| **禁止编造** | 粉丝量、播放量、变现金额。这些平台可查，造假极易识破 |

### 3. 直播经验（任何平台）

| 项目 | 内容 |
|-----|-----|
| **可证明的岗位能力** | 核心能力：镜头感、话术、控场、销售转化、数据理解 |
| **简历价值等级** | ★★★★★（最高） |
| **推荐表达方向** | 平台+品类+时长→单场/月均GMV→核心数据（转化率、停留时长）→个人贡献点 |
| **追问点** | ① 播了多久？什么品类？② 单场最高GMV？平均在线人数？③ 话术是自己写还是运营给？④ 有没有录屏？⑤ 为什么离职？ |
| **无数据时的处理** | 强调"累计直播X小时"、"带过X个品类"、"熟悉X平台后台操作"。没有GMV就强调"从0到1"或"兼职验证" |
| **禁止编造** | GMV、转化率、场观。这些是面试必深挖的数字，造假立即出局 |

## 通用追问清单（Agent使用）

当用户提到任何经历时，按此顺序追问：

1. **规模/数据**："具体数据是多少？"（粉丝量、销售额、播放量、人数）
2. **时间/持续性**："做了多久？是持续的还是断断续续？"
3. **个人贡献**："这是团队做的还是你独立做的？你具体负责什么？"
4. **结果/证据**："有录屏/链接/截图/作品可以看吗？"
5. **迁移点**："你觉得这段经历对做主播有什么帮助？"
6. **卡点/失败**："有没有遇到过困难？怎么解决的？"

## 无数据时的通用处理策略

| 场景 | 策略 |
|-----|-----|
| 有经历但无数据 | 强调"从0到1""自主尝试""验证意愿"，用过程指标代替结果指标 |
| 经历很零散 | 提炼共同能力线："多次尝试面向用户的表达/销售类工作" |
| 完全零相关经历 | 引导用户录制一段模拟直播，作为"最小作品集" |
| 数据很小不好意思说 | 鼓励诚实："真实的小数据 > 虚假的大数据" |

## 禁止编造的内容（红线）

| 类别 | 说明 | 后果 |
|-----|-----|-----|
| **GMV/销售额** | 最核心的造假点 | 面试追问3层必露馅，直接出局 |
| **粉丝量/播放量** | 平台公开可查 | 提供账号链接即可验证 |
| **平台经验** | 没播过抖音说播过 | 问后台操作、流量入口即露馅 |
| **职级/职务** | "负责人"vs"参与者" | 背调或细节追问可识破 |
| **时间线** | 经历重叠、空窗期隐藏 | 履历矛盾 |
| **学历/证书** | 学信网可查 | 严重诚信问题 |

> **Agent原则**：宁可让用户简历"单薄但真实"，也不要"丰满但虚假"。主播行业极度依赖作品和数据验证，造假存活率接近0。
