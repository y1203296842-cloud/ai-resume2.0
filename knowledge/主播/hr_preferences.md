# 主播 — HR筛选偏好

> 可信度标注：★1-5，★★★★★ 为最高可信度

---

## HR最看重的能力（按优先级）

### P0 — 决定是否约面

| 能力 | 权重 | 判断依据 |
|-----|:---:|---------|
| **直播录屏/作品** | 最高 | 这是主播的"作品集"，没有作品几乎不可能约面。HR在30秒内判断是否留人、说话是否自然 |
| **销售转化数据** | 极高 | GMV、转化率、单场最高记录。数字是最硬通货 |
| **平台经验匹配度** | 高 | 招聘抖音主播，有抖音经验 > 有淘宝经验 > 无经验 |
| **形象与镜头感** | 高 | 照片/视频中的第一印象，颜值不是唯一标准但"顺眼"是门槛 |

### P1 — 影响综合评估

| 能力 | 权重 | 判断依据 |
|-----|:---:|---------|
| **话术逻辑与表达** | 高 | 直播中产品讲解是否有结构（痛点→卖点→信任→促单） |
| **行业/品类匹配** | 中高 | 美妆主播跳食品相对容易，跳3C需要学习成本 |
| **稳定性** | 中 | 过往工作经历是否频繁跳槽，主播行业流动性高，HR怕培养后流失 |
| **学习意愿** | 中 | 是否主动研究平台规则、同行案例、数据复盘 |

### P2 — 加分项

| 能力 | 权重 | 判断依据 |
|-----|:---:|---------|
| **自带粉丝/私域** | 中 | 有基础粉丝量可降低冷启动成本 |
| **多平台经验** | 低 | 有跨境/TikTok经验在某些公司有溢价 |
| **专业证书/学历** | 低 | 播音主持专业是加分项，但非硬性要求 |

## 最有价值的经历

| 经历 | 价值等级 | 为什么 |
|-----|:-------:|-------|
| 有完整直播录屏且数据可查 | ★★★★★ | 唯一能让HR"眼见为实"的证据 |
| 单场GMV过10万/月GMV过百万 | ★★★★★ | 直接证明变现能力 |
| 从0到1起号成功 | ★★★★☆ | 证明全链路能力，不只是"念稿子" |
| 垂类深耕（如专注美妆2年+） | ★★★★☆ | 证明专业度和粉丝黏性 |
| 有爆款短视频引流案例 | ★★★★☆ | 证明内容能力和流量敏感度 |
| 带团队/培训新人经验 | ★★★☆☆ | 证明管理潜力和方法论沉淀 |

---

## 简历必须体现的内容

1. **直播数据**：用数字说话（GMV、场观、停留时长、转化率、粉丝增量）
2. **平台+品类**：明确说明在哪个平台、带什么货
3. **时间段**：每段经历的起止时间，证明稳定性
4. **作品链接**：录屏链接、短视频账号、直播间链接（如有）
5. **个人形象照**：清晰、专业、符合品类调性

## 几乎没人看的内容

| 内容 | 原因 |
|-----|-----|
| 大学课程列表 | 主播岗位学历门槛极低 |
| 与直播无关的兼职经历（如发传单、家教） | 除非能提炼出 transferable skills |
| 自我评价中的"性格开朗、善于沟通" | 空话，HR通过视频判断 |
| 兴趣爱好 | 除非与品类强相关（如美妆爱好者应聘美妆主播） |
| 英语水平（无跨境经验时） | 国内直播几乎用不到 |

---

## 容易淘汰的内容

| 内容 | 淘汰原因 |
|-----|---------|
| 简历无作品/录屏 | 主播是作品导向岗位，无法验证能力 |
| 数据夸大明显（如新人月GMV千万） | 行业常识判断造假 |
| 频繁跳槽（每份工作<3个月） | 主播行业培养成本高，HR怕流失 |
| 形象照过度PS/与直播画面差距大 | 诚信问题 |
| 透露计划短期过渡/考研/考公 | 稳定性存疑 |
| 对销售转化避而不谈，只强调"内容创作" | 岗位认知偏差 |

## 不同企业类型偏好

### MCN机构

| 偏好 | 说明 |
|-----|-----|
| 可塑性 > 经验 | 喜欢"白纸"，便于按公司方法论培养 |
| 外形条件权重高 | 尤其是娱乐主播和美妆主播 |
| 能接受高强度/高淘汰率 | MCN通常有试播期，不通过即淘汰 |
| 配合度 > 个性 | 需要服从公司排期、话术、选品安排 |
| 看重成长性 | 是否有成为头部主播的潜力 |

### 品牌方（自营团队）

| 偏好 | 说明 |
|-----|-----|
| 稳定性 > 爆发力 | 品牌自播追求日销稳定，不追求单场爆发 |
| 形象气质匹配品牌调性 | 高端品牌需要"高级感"，平价品牌需要"亲和力" |
| 学习能力 > 当前数据 | 需深度理解品牌文化和产品知识 |
| 团队协作意识 | 自播团队通常配置完整，需配合运营、场控 |
| 合规意识 | 品牌方对虚假宣传、违规用词零容忍 |

### 平台方（抖音/快手/淘宝等）

| 偏好 | 说明 |
|-----|-----|
| 生态理解深度 | 是否理解平台算法、政策、资源位机制 |
| 商家服务经验 | 是否有服务商家/达人的经验 |
| 数据分析能力 | 平台岗位偏策略和运营，非一线直播 |
| 跨部门协作 | 需对接商家、达人、产品、技术多团队 |
| 学历门槛相对较高 | 平台方 corporate 岗位通常要求本科+ |
