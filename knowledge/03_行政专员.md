## 一、岗位介绍

**一句话介绍**：负责企业日常行政事务管理、办公环境维护、物资采购、会议组织及后勤保障，确保公司高效运转的基础性支持岗位。

**主要工作内容**：
- 办公环境管理与维护
- 办公用品及固定资产采购与管理
- 会议组织与接待安排
- 员工福利及活动组织
- 文件档案管理
- 考勤及基础人事支持
- 行政费用预算与控制
- 供应商对接与管理
- 公司制度执行与监督
- 差旅及车辆管理

**适合什么样的人**：
- 细心、耐心、有条理
- 服务意识强
- 沟通协调能力好
- 能承受琐碎事务
- 熟练使用Office办公软件
- 有亲和力，善于处理人际关系

## 二、岗位职责（高频真实JD提炼）

1. 负责公司日常行政事务处理，保障办公环境整洁有序
2. 管理办公用品及固定资产，完成采购、入库、领用及盘点
3. 组织公司会议，包括会议室预定、设备调试、会议记录及纪要整理
4. 负责来访客户接待，包括引导、茶水准备及会议室安排
5. 管理公司文件档案，完成归档、借阅及保密管理
6. 协助员工考勤管理，统计考勤数据并处理异常
7. 组织员工活动及团建，提升团队凝聚力
8. 管理行政费用预算，控制各项行政支出
9. 对接物业、保洁、绿植等供应商，监督服务质量
10. 负责公司快递、信件收发及名片印制
11. 协助办理员工入职/离职手续及办公用品配发
12. 管理公司车辆及员工差旅预订
13. 执行公司行政管理制度，监督制度落实情况
14. 处理突发事件及临时行政需求
15. 协助其他部门完成日常行政支持工作

## 三、HR真正关注什么

### HR最看重的能力（按优先级）

| 优先级 | 能力项 | 说明 |
|--------|--------|------|
| P0 | 细致认真 | 行政工作容错率低，粗心是大忌 |
| P0 | 沟通协调能力 | 对接内外部人员，需要良好的沟通 |
| P0 | Office熟练度 | Excel表格、Word文档、PPT是基本功 |
| P1 | 服务意识 | 行政是服务岗位，态度决定一切 |
| P1 | 条理性 | 能同时处理多项事务且不出错 |
| P1 | 应变能力 | 能处理突发情况和临时需求 |
| P2 | 成本意识 | 采购物品时能比价、控预算 |
| P2 | 保密意识 | 能妥善处理敏感信息 |

### 最有价值的经历
- 有行政/助理类实习或兼职经历
- 组织过中大型活动（校庆、晚会、运动会等）
- 管理过物资/经费/档案
- 有接待/会务经验
- 熟练使用Excel做数据统计

### 必须体现的内容
- 具体处理过什么行政事务
- 管理过的物资/资产规模
- 组织过的活动规模
- Office技能水平（最好有作品）

### 几乎没人看的内容
- "性格开朗"（主观描述，无价值）
- "乐于助人"（同理）
- 与行政无关的兴趣爱好
- 大量证书罗列（除非相关）

### 容易淘汰的内容
- 简历中出现错别字（行政岗位基本要求）
- 格式混乱、排版不整齐（专业素养不足）
- 没有任何组织/协调经历
- Office技能写"精通"但说不出具体会什么

## 八、包装规则

### 适合重点包装的内容

- **有组织/协调/管理性质的经历**：活动组织、班级管理、物资管理
- **有数据支撑的成果**：管理经费金额、组织活动人数、文件数量
- **体现细致和条理性的经历**：档案整理、数据统计、流程优化

### 正常描述即可的内容

- 基础的行政协助工作
- 日常事务处理
- 简单的接待工作

### 绝对不能夸大的内容

- 管理范围和职责
- "负责"的程度（参与≠主导）
- 管理的人员数量
- 经费金额

### 禁止编造的内容

- 任何金额数据
- 未参与的活动或项目
- 虚构的职位或荣誉
- 不存在的技能

### 用户提供数据必须保留

- 经费金额、人数、数量等原始数据
- 时间范围
- 具体的职责范围

### 没有数据绝不能生成的内容

- 不能编造任何数字
- 不能夸大管理规模
- 不能把协助写成主导

## 十、常见错误

### 大学生最容易犯的问题

1. **格式不整齐**：行政岗位对格式和细节要求高，简历本身就是能力展示
2. **有错别字**：这是最致命的错误
3. **描述太泛**："协助行政工作"没有任何信息量
4. **忽视Office技能**：不写具体会什么Excel函数、PPT技能
5. **缺乏服务意识**：描述中看不到"服务"和"支持"的意识

### 转行最容易犯的问题

1. **不解释关联性**：原有工作与行政的关联没有建立
2. **忽视 transferable skills**：客服的耐心、销售的沟通都是可迁移的
3. **过度强调管理**：应聘行政专员却写了很多"管理"经历
4. **薪资期望过高**：对行政岗位薪资水平不了解

### 已有工作经验最容易犯的问题

1. **职责范围不清**："负责所有行政工作"太泛
2. **没有量化成果**："管理办公用品"没有金额或数量
3. **不更新知识**：还在用旧的办公工具
4. **跳槽频繁不解释**：行政岗位流动性高，但需合理解释

## 十一、真实案例分析

### 案例1：应届生+学生会经历

**原简历**：
> 学生会办公室干事，帮忙整理文件。

**优化后**：
> 负责学生会文件收发及档案管理，整理归档各类文件300+份，建立文件编号体系；负责部门例会记录，输出会议纪要20+份；协助完成3场大型活动物资采购及现场支持，活动覆盖1000+人。

**优秀原因**：
- 具体化了工作内容和数量
- 体现了档案管理能力
- 体现了会议组织能力
- 体现了活动支持能力
- 数据支撑充分

### 案例2：转行+客服背景

**原简历**：
> 做过1年客服，想转行政。

**优化后**：
> 1年客户服务经验，培养了良好的服务意识及沟通协调能力；负责客户咨询处理及问题跟进，日均处理咨询50+条，客户满意度保持95%以上；熟练使用Excel进行数据统计及报表制作，具备扎实的办公软件操作能力。

**优秀原因**：
- 建立了客服与行政的关联（服务意识、沟通）
- 体现了数据能力（Excel统计）
- 体现了细致和耐心（客服工作要求）
- 有具体数据支撑（50+条、95%满意度）

### 案例3：有经验者

**原简历**：
