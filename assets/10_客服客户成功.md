## 一、岗位介绍

**一句话介绍**：通过专业的产品咨询、问题解答、投诉处理及客户关系维护，提升客户满意度、降低流失率并促进客户持续价值贡献的服务型岗位（客户成功更侧重主动帮助客户实现业务目标）。

**主要工作内容**：
- 客户咨询解答与问题处理
- 投诉处理与危机化解
- 客户关系维护与满意度提升
- 客户使用情况跟踪与主动服务
- 客户流失预警与挽留
- 客户需求收集与反馈传递
- 产品培训与使用指导
- 客户续约与增购促进
- 客户成功案例整理与输出
- 客服数据记录与分析

**适合什么样的人**：
- 耐心、细心、服务意识强
- 沟通表达能力强，善于倾听
- 情绪管理能力好，不易被激怒
- 学习能力好，能快速掌握产品知识
- 有同理心，能站在客户角度思考
- 能接受重复性工作和倒班制度

## 二、岗位职责（高频真实JD提炼）

1. 负责客户咨询接待，通过电话/在线/邮件解答客户问题
2. 处理客户投诉，协调相关部门解决客户问题
3. 维护客户关系，定期回访并收集客户反馈
4. 跟踪客户产品使用情况，主动识别并解决潜在问题
5. 进行客户流失预警，执行挽留方案
6. 收集客户需求及建议，反馈至产品/运营部门
7. 为客户提供产品使用培训及指导
8. 协助客户完成 onboarding 及功能配置
9. 促进客户续约及增购，完成续约/增购指标
10. 整理客户成功案例，输出案例文档
11. 输出客服日报/周报，记录服务数据
12. 优化客服话术及服务流程
13. 建立客户分级服务体系
14. 协助完善知识库及FAQ
15. 完成上级交办的其他客户服务工作

## 三、HR真正关注什么

### HR最看重的能力（按优先级）

| 优先级 | 能力项 | 说明 |
|--------|--------|------|
| P0 | 沟通能力 | 客服就是沟通，表达清晰有耐心 |
| P0 | 服务意识 | 真心想帮客户解决问题 |
| P0 | 情绪管理 | 面对投诉和刁难能保持冷静 |
| P1 | 产品知识 | 快速掌握产品，能专业解答 |
| P1 | 问题解决 | 能独立解决常见问题 |
| P1 | 同理心 | 能站在客户角度理解问题 |
| P2 | 数据分析 | 能分析客服数据，发现规律 |
| P2 | 主动服务 | 客户成功需要主动服务思维 |

### 最有价值的经历
- 有客服/服务类实习或兼职经验
- 有处理投诉或冲突的经历
- 有客户满意度提升的成果
- 有客户需求收集和反馈的经历
- 有培训或指导他人的经历

### 必须体现的内容
- 服务过的客户类型和数量
- 处理的咨询/投诉类型
- 使用的客服工具和系统
- 客户满意度或解决率数据

### 几乎没人看的内容
- "性格开朗"（主观）
- "乐于助人"（主观）
- 与客服无关的兴趣爱好
- 大量证书罗列

### 容易淘汰的内容
- 没有任何服务类经历
- 对客服岗位有错误认知（"就是接电话"）
- 情绪管理能力差（简历中透露急躁）
- 沟通能力不足（简历表达不清）

## 八、包装规则

### 适合重点包装的内容

- **有明确服务数据的经历**：接待量、满意度、解决率
- **投诉处理成功案例**：化危为机的经历
- **客户需求收集和反馈**：推动了产品改进
- **客户续约/增购成果**：客户成功导向

### 正常描述即可的内容

- 基础的咨询解答
- 常规的问题处理
- 简单的客户回访

### 绝对不能夸大的内容

- 服务客户数量
- 满意度数据
- "独立负责"（需确认实际角色）
- 投诉处理难度

### 禁止编造的内容

- 任何满意度/解决率数据
- 未参与的服务项目
- 虚构的客户案例
- 不存在的荣誉

### 用户提供数据必须保留

- 所有原始服务数据
- 满意度评分
- 时间范围

### 没有数据绝不能生成的内容

- 不能编造满意度
- 不能写"解决率XX%"无依据
- 不能把协助写成主导

## 十、常见错误

### 大学生最容易犯的问题

1. **无服务经历**：没有任何与客户服务相关的经历
2. **忽视软技能**：沟通、耐心、同理心等能力没有展示
3. **对产品理解浅**：只懂"服务"不懂"产品"
4. **情绪管理差**：简历中透露急躁或不耐烦
5. **不更新认知**：以为客服就是"接电话"

### 转行最容易犯的问题

1. **不解释关联性**：原有经历与客服的可迁移能力没有提炼
2. **忽视 transferable skills**：销售的沟通、行政的细致都是可迁移的
3. **薪资期望过高**：对客服岗位薪资不了解
4. **不适应考核**：对服务指标考核有抵触

### 已有工作经验最容易犯的问题

1. **数据造假**："满意度100%"不现实
2. **不更新知识**：还在用过时的客服方法
3. **忽视数字化**：不懂智能客服和CRM系统
4. **缺乏主动服务意识**：被动等待客户联系

## 十一、真实案例分析

### 案例1：应届生+电商客服

**原简历**：

**优化后**：

- 有具体服务数据（80+人、3→1分钟、97%）
- 展示了问题解决能力（退换货、投诉）
- 体现了主动服务意识（收集反馈、推动优化）
