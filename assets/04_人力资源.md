## 一、岗位介绍

**一句话介绍**：负责企业人才的选、用、育、留、退全生命周期管理，通过招聘、培训、绩效、薪酬、员工关系等模块，为企业匹配和发展人才的战略性支持岗位。

**主要工作内容**：
- 招聘与人才选拔
- 培训与发展
- 绩效管理
- 薪酬福利管理
- 员工关系管理
- 人力资源规划
- 企业文化建设
- 劳动关系处理
- 人事制度制定与执行
- 人力资源数据分析

**适合什么样的人**：
- 沟通协调能力强
- 对人有敏锐的洞察力
- 逻辑思维清晰
- 能承受招聘压力和员工情绪
- 原则性强但又不失灵活
- 对人力资源专业有兴趣

---

## 二、岗位职责（高频真实JD提炼）

1. 负责招聘全流程，包括需求对接、渠道选择、简历筛选、面试安排及offer跟进
2. 维护和拓展招聘渠道，优化招聘效率及成本
3. 组织新员工入职培训，协助完成 onboarding 流程
4. 负责员工考勤、假期及档案管理
5. 协助绩效考核方案的制定与执行
6. 负责薪酬核算及社保公积金办理
7. 处理员工关系事务，包括入离职、转正、调岗等
8. 解答员工人事政策咨询，维护良好的员工关系
9. 协助制定和完善人力资源管理制度
10. 开展员工满意度调研，输出分析报告
11. 组织企业文化活动，提升员工归属感
12. 负责人力资源数据统计及报表输出
13. 处理劳动纠纷及仲裁事务
14. 协助人才盘点及梯队建设
15. 跟踪人力资源行业动态及政策法规变化

## 三、HR真正关注什么

### HR最看重的能力（按优先级）

| 优先级 | 能力项 | 说明 |
|--------|--------|------|
| P0 | 沟通协调能力 | HR每天80%时间在沟通 |
| P0 | 细致认真 | 薪酬、合同等容不得差错 |
| P0 | 抗压能力 | 招聘有KPI，员工关系有情绪 |
| P1 | 逻辑思维 | 制度设计、流程优化需要 |
| P1 | 学习能力 | 劳动法规经常更新 |
| P1 | 亲和力 | 员工愿意找你倾诉和咨询 |
| P2 | 数据分析 | 人力数据分析越来越重要 |
| P2 | 谈判能力 | offer谈判、离职协商需要 |

### 最有价值的经历
- 有招聘全流程经验（从需求到入职）
- 有培训组织经验
- 有绩效或薪酬实操经验
- 处理过劳动纠纷或员工关系问题
- 有人力数据分析经验

### 必须体现的内容
- 招聘了多少人、用了什么渠道
- 组织了什么培训、多少人参加
- 处理过多少入离职
- 熟悉哪些劳动法规

### 几乎没人看的内容
- "热爱人力资源工作"（空泛）
- "性格外向"（主观）
- 与HR无关的证书
- 大量课程名称罗列

### 容易淘汰的内容
- 对劳动法规一无所知
- 把"帮忙收过简历"写成"负责招聘"
- 数据造假（"独立招聘100人"应届生几乎不可能）
- 错别字（HR岗位基本要求）

## 八、包装规则

### 适合重点包装的内容

- **有全流程招聘经验**：从需求到入职的完整链路
- **有培训组织经验**：课程设计、讲师对接、效果评估
- **有数据支撑的成果**：招聘效率提升、员工满意度等
- **体现沟通协调的经历**：多方对接、矛盾调解

### 正常描述即可的内容

- 基础的简历筛选
- 常规的入离职办理
- 简单的考勤统计

### 绝对不能夸大的内容

- 招聘人数和效率
- "独立负责"（需确认实际职责）
- "主导"（需确认实际角色）
- 管理的人员数量

### 禁止编造的内容

- 任何人数数据
- 未参与的项目
- 虚构的证书或资质
- 不存在的劳动法知识

### 用户提供数据必须保留

- 招聘数量、渠道数据
- 培训人次、满意度
- 入离职数量
- 原始数据不得修改

### 没有数据绝不能生成的内容

- 不能编造招聘数量
- 不能写"提升XX%"无依据
- 不能把协助写成主导

## 九、优秀表达（100条）

1. 招人 → 负责招聘全流程，从需求对接到offer跟进，确保岗位按时交付
2. 看简历 → 完成简历筛选及初步评估，确保候选人质量符合岗位要求
3. 约面试 → 协调面试官及候选人时间，安排面试流程并跟进反馈
4. 做面试 → 参与结构化面试，评估候选人胜任力及文化匹配度
5. 谈offer → 完成offer谈判及发放，跟进候选人入职进度
6. 做校招 → 负责校园招聘项目，完成宣讲会组织及面试安排
7. 做社招 → 负责社会招聘，拓展招聘渠道并优化招聘效率

9. 做内推 → 搭建员工内推机制，提升内推比例及质量

## 十、常见错误

### 大学生最容易犯的问题

1. **劳动法知识空白**：对基本劳动法规一无所知
2. **过度强调"喜欢和人打交道"**：这是HR的基本要求，不是竞争力
3. **无实操经验**：只学过理论，没有任何实践
4. **数据造假**："协助招聘50人"没有可信度
5. **分不清HR模块**：把招聘、培训、薪酬混为一谈

### 转行最容易犯的问题

1. **不解释关联性**：原有工作与HR的可迁移能力没有提炼
2. **忽视软实力**：管理、协调、沟通等 transferable skills 没有展示
3. **证书迷信**：以为考个HR证书就能转行
4. **薪资期望不合理**：对HR岗位薪资不了解

### 已有工作经验最容易犯的问题

1. **模块单一**：只做过招聘，其他模块完全不提学习能力
2. **数据注水**：把团队数据写成个人成绩
3. **忽视合规风险**：处理过敏感问题但不注意保密
4. **不更新知识**：还在用过时的招聘渠道和方法

## 十一、真实案例分析

### 案例1：应届生+社团招新

**原简历**：
> 社团招新负责人，帮忙面试新生。

**优化后**：
> 负责社团年度招新项目，设计线上线下宣传方案，覆盖新生2000+人；独立完成简历筛选及面试安排，面试候选人80+人，录取新成员25人；组织新成员破冰培训，设计团队融入活动，新人留存率达90%。

**优秀原因**：
- 完整项目闭环（宣传→筛选→面试→培训）
- 数据支撑充分（2000+、80+、25、90%）
- 体现了招聘全流程能力
- "留存率"体现了对结果的关注

### 案例2：转行+教师背景

**原简历**：
> 做过2年老师，想转HR。

**优化后**：
> 2年教育工作经验，培养了良好的沟通表达及人才培养能力；负责班级40人日常管理及家长沟通，处理各类学生问题并协调家校关系；组织家长会及学生表彰活动10+场，具备较强的活动组织能力；熟悉教育心理学，有助于员工关系管理及人才评估。

**优秀原因**：
- 建立了教育与HR的关联（沟通、培养、活动组织）
- 体现了人员管理能力（40人班级）
- 体现了活动组织能力（10+场）
- 补充了心理学优势

### 案例3：有经验者

**原简历**：
> 负责公司招聘工作。

**优化后**：
> 负责公司社会招聘及校园招聘，年度完成招聘需求80+人，招聘达成率95%；优化招聘流程，将平均招聘周期从30天缩短至20天；拓展内推渠道，内推占比从10%提升至25%；建立人才储备库，维护潜在候选人500+人，保障关键岗位快速补员。

**优秀原因**：
- 数据支撑充分（80+人、95%、30→20天、10%→25%）
- 展示了多方面能力（社招+校招、流程优化、渠道拓展）
- "人才储备库"体现了前瞻性思维
- 每个成果都有具体数字
