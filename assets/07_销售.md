## 一、岗位介绍

**一句话介绍**：通过客户开发、需求挖掘、产品推介、谈判签约及客情维护，实现公司产品或服务的销售目标，为企业创造直接收入的业务岗位。

**主要工作内容**：
- 客户开发与线索获取
- 客户需求挖掘与分析
- 产品/服务推介与演示
- 商务谈判与合同签约
- 销售目标达成与业绩管理
- 客户关系维护与复购促进
- 市场信息收集与反馈
- 销售数据记录与分析
- 客户投诉处理与问题解决
- 销售团队协作与经验分享

**适合什么样的人**：
- 沟通表达能力强，有说服力
- 抗压能力强，能接受业绩考核
- 目标导向，追求结果
- 学习能力好，能快速掌握产品知识
- 情商高，善于处理人际关系
- 不排斥被拒绝，心态积极

## 二、岗位职责（高频真实JD提炼）

1. 负责公司产品的销售推广，完成个人销售指标
2. 开发新客户，拓展销售渠道及客户资源
3. 挖掘客户需求，提供针对性的产品解决方案
4. 进行产品演示及方案讲解，促成签约
5. 维护客户关系，提升客户满意度及复购率
6. 跟进合同签订及款项回收
7. 收集市场及竞品信息，反馈客户需求
8. 建立客户档案，完善客户信息管理系统
9. 处理客户投诉及售后问题协调
10. 参与销售策略制定及目标分解
11. 完成销售报表及数据更新
12. 协助市场部门开展推广活动
13. 培养并维护核心客户及大客户关系
14. 参与销售培训及技能提升
15. 完成上级交办的其他销售任务

## 三、HR真正关注什么

### HR最看重的能力（按优先级）

| 优先级 | 能力项 | 说明 |
|--------|--------|------|
| P0 | 沟通能力 | 销售就是靠沟通 |
| P0 | 抗压能力 | 业绩压力和拒绝是常态 |
| P0 | 结果导向 | 销售只看数字 |
| P1 | 客户开发 | 能主动找到客户 |
| P1 | 谈判能力 | 能促成签约 |
| P1 | 学习能力 | 快速掌握产品和行业知识 |
| P2 | 客户维护 | 能做长期关系 |
| P2 | 数据分析 | 能分析自己的销售数据 |

### 最有价值的经历
- 有明确的销售业绩数据
- 有客户开发和维护的成功案例
- 有谈判和签约的完整案例
- 有处理客户异议和投诉的经历
- 有团队协作和带新人的经历

### 必须体现的内容
- 具体销售业绩（金额/数量/完成率）
- 客户类型和数量
- 销售的产品或服务
- 使用的销售方法

### 几乎没人看的内容
- "性格外向"（主观）
- "喜欢与人打交道"（基本要求）
- 与销售无关的兴趣爱好
- 大量课程名称罗列

### 容易淘汰的内容
- 没有任何销售相关经历
- 把"帮家里看店"写成"负责销售"
- 业绩数据造假
- 对销售岗位有错误认知（"销售就是骗人"）

## 八、包装规则

### 适合重点包装的内容

- **有明确销售业绩的经历**：任何有数字的销售成果
- **完整销售案例**：从开发到签约的完整过程
- **客户维护成果**：复购、转介绍等长期关系
- **体现销售技巧的经历**：谈判、异议处理、方案推荐

### 正常描述即可的内容

- 基础的客户接待
- 常规的产品介绍
- 简单的数据记录

### 绝对不能夸大的内容

- 销售业绩数据
- 客户数量
- "独立负责"（需确认实际角色）
- "带领团队"（需确认实际管理）

### 禁止编造的内容

- 任何销售数据
- 未参与的项目
- 虚构的客户
- 不存在的荣誉

### 用户提供数据必须保留

- 所有原始业绩数据
- 增长率需说明基准
- 时间范围

### 没有数据绝不能生成的内容

- 不能编造销售额
- 不能写"完成率XX%"无依据
- 不能把协助写成主导

## 九、优秀表达（100条）

### 客户开发类

1. 找客户 → 通过多渠道开发潜在客户，建立客户资源库
2. 打电话 → 通过电话触达潜在客户，挖掘需求并预约拜访
3. 跑客户 → 进行客户拜访，建立初步信任关系
4. 做地推 → 开展线下推广活动，直接触达目标用户
5. 做社群 → 通过社群运营获取潜在客户线索
6. 做转介绍 → 维护老客户关系，获取客户转介绍
7. 做渠道 → 拓展合作渠道，建立获客来源
8. 做陌拜 → 开展陌生客户拜访，开拓新客户资源
9. 做展会 → 参加行业展会，收集潜在客户信息
10. 做线上 → 通过线上渠道获取销售线索

### 需求挖掘类

11. 挖需求 → 通过提问技巧深入挖掘客户真实需求
12. 做调研 → 了解客户业务现状及痛点
13. 做分析 → 分析客户需求，匹配产品解决方案
14. 做诊断 → 诊断客户问题，提出针对性建议
15. 做方案 → 根据客户需求定制解决方案
16. 做演示 → 进行产品演示，展示产品价值
17. 做讲解 → 清晰讲解产品功能及优势
18. 做对比 → 与竞品对比，突出产品差异化优势
19. 做价值 → 向客户传递产品核心价值
20. 做匹配 → 将产品功能与客户需求精准匹配

### 谈判签约类

21. 做谈判 → 进行商务谈判，协商价格及合作条款
22. 做报价 → 制定并提交客户报价方案
23. 做合同 → 跟进合同签订流程
24. 做异议 → 处理客户异议及顾虑

## 十、常见错误

### 大学生最容易犯的问题

1. **无销售经历**：没有任何与销售相关的经历
2. **数据造假**："月销售额10万"没有可信度
3. **不懂销售流程**：不知道销售的基本流程
4. **忽视软技能**：沟通、抗压、学习等能力没有展示
5. **对销售有偏见**：简历中透露出对销售岗位的不屑

### 转行最容易犯的问题

1. **不解释关联性**：原有经历与销售的可迁移能力没有提炼
2. **忽视 transferable skills**：客服的沟通、运营的转化都是可迁移的
3. **薪资期望过高**：对销售岗位薪资结构不了解
4. **不适应考核**：对业绩考核有抵触

### 已有工作经验最容易犯的问题

1. **业绩注水**：把团队业绩写成个人业绩
2. **客户资源造假**：虚构客户名称和合作
3. **不更新知识**：还在用过时的销售方法
4. **忽视客户维护**：只关注开发，不关注维护

## 十一、真实案例分析

### 案例1：应届生+校园代理

**原简历**：
> 做过校园代理，卖过一些产品。

**优化后**：
> 负责XX品牌在校园渠道的销售推广，通过地推、社群及朋友圈触达目标用户；通过需求沟通了解同学痛点，针对性推荐产品方案；月度完成销售额5000元，在团队中排名前20%；维护客户关系，获得老客户复购及转介绍。

**优秀原因**：
- 展示了完整的销售流程（触达→沟通→推荐→成交）
- 有具体数据（5000元、前20%）
- 体现了客户维护意识（复购、转介绍）
- 有排名数据体现竞争力

### 案例2：转行+客服背景

**原简历**：
> 做过2年客服，想转销售。

**优化后**：
> 2年客户服务经验，深度理解客户需求及沟通技巧；通过客户沟通识别潜在购买需求，成功转化客户升级服务200+次；熟悉公司产品体系，能为客户提供针对性解决方案；具备良好的抗压能力及目标意识，适应业绩考核模式。

**优秀原因**：
- 建立了客服与销售的关联（需求识别、转化）
- 体现了转化能力（200+次升级）
- 体现了产品知识
- 体现了抗压和目标意识

### 案例3：有经验者

**原简历**：
> 负责大客户销售，完成业绩目标。

**优化后**：
> 负责XX行业大客户销售，年度销售目标500万，实际完成620万，达成率124%；独立开发新客户15家，其中3家成为年采购额超50万的核心客户；通过客户深度运营，核心客户续约率100%，年度复购额增长30%；建立行业客户地图，输出大客户开发方法论。

**优秀原因**：
- 数据支撑充分（500→620万、124%、15家、100%、30%）
- 展示了多方面能力（开发、维护、复购）
- "方法论"体现了专业沉淀
- 每个成果都有具体数字
